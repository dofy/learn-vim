# Vim のモード

Vim では同じキーでもモードによって動作が異なります。すべてのモードを暗記する必要は
ありません。まず一つの循環を覚えます。ノーマルモードで操作を選び、文字を入力するとき
挿入モードへ入り、完了したら `Esc` でノーマルモードへ戻ります。

```text
Normal -- i/a/o など --> Insert
   ^                      |
   +-------- Esc ---------+
```

現在のモードが分からない場合、`Esc` を押すのが通常は安全な出発点です。

## ノーマルモード

ノーマルモードは Vim のデフォルトで、編集操作の中心です。キーは文字入力ではなく、
移動、削除、コピー、貼り付け、取り消しなどを実行します。たとえば `h`、`j`、`k`、
`l` は移動、`u` は変更の取り消しです。[第 1 章](chapter01.md)から学びます。

## 挿入モード

挿入モードは文字を入力します。ノーマルモードから、異なる位置で入力を始められます。

- `i` 現在の文字の前
- `a` 現在の文字の後ろ
- `I` 行の最初の非空白文字の前
- `A` 行末
- `o` 現在行の下に新しい行
- `O` 現在行の上に新しい行

入力後は `Esc` でノーマルモードへ戻ります。`Ctrl-[` も `Esc` と同じです。

## ビジュアルモード

ビジュアルモードは削除やコピーの前にテキストを選択します。

- `v` 文字単位で選択
- `V` 行単位で選択
- `Ctrl-v` 矩形ビジュアルモードで長方形を選択

ノーマルモードの移動コマンドで選択範囲を広げ、`Esc` でキャンセルします。

> 次の `{` にカーソルを置き、`v`、`%` の順に押して対応する `}` まで選択します。
> `Esc` を押し、ノーマルモードへ戻ったことを確認してください。

```javascript
const bio = () => {
  console.log('自由が人々を導く。');
  console.log('· Why so serious? ·');
};
```

## コマンドラインモード

ノーマルモードで `:` を押すとコマンドラインモードへ入ります。`:w`、`:q`、`:e`、
`:set`、`:help` などを実行できます。`Enter` で実行し、`Esc` でキャンセルします。

知らないコマンドは `:help <command>` で調べます。例：`:help :write`。コマンド一覧を
暗記するより、Vim 内蔵ヘルプの引き方を覚えるほうが役立ちます。

## 循環を練習する

> ノーマルモードから `i` を押し、3 文字入力して `Esc` を押します。`u` で取り消し、
> `Ctrl-r` でやり直し、もう一度 `Esc` を押します。各手順のモードを説明できたら
> [第 1 章](chapter01.md)へ進んでください。

Vim には Replace、Select、Ex、Prompt、Terminal などのモードもあります。必要に
なったとき `:help` で学べばよく、今すべてを覚える必要はありません。
